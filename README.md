AI의 판단을 로봇과 실제 시스템의 동작으로 연결하는 AI·Robotics·Embedded SW 개발자 포트폴리오입니다.

**Live:** https://gwonyeongho.github.io/portfolio/

## 주요 프로젝트

- 문화유산 AI 복원 · VR 박물관
- PipeCheckkk 하수도 탐사 로봇
- Smart Factory Twin
- Karaoke AI Agent
- 신체 치수 예측
- 해외여행 커뮤니티 앱

## 수정 방법

`index.html`의 `CONTENT` 객체에서 소개·기술·프로젝트 내용을 수정합니다.

```bash
npx serve .
```

`master` 브랜치에 push하면 GitHub Pages로 배포됩니다.
