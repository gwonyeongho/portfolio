## 노래방 이미지

`karaoke-ui.webp`는 실제 저장소의 프론트엔드 코드를 브라우저로 렌더링한 초기 UI이다. 음성 API와 Ollama 모델을 실행해 제어 성공을 검증한 화면은 아니다. `karaoke-cover.webp`는 해당 UI를 배치해 제작한 포트폴리오 대표 이미지이다. 가상의 명령 성공 결과나 성능 지표를 삽입하지 않았다.

## 개인 역할과 평가 기록 재확인

PipeCheckkk는 로컬 자기소개서 초안과 사용자가 직접 설명한 기존 자소서 문장을 참고하였다. 개인 담당은 VLM의 주행 영상 해석과 모터값 조절, 하네스 구성, 반복 주행에서 나타난 전복과 경로 이탈 조건의 정리 및 자세 기반 제어 규칙 보완이다. 기존 근거표의 일부 '허용 행동 선택만 수행' 요약보다 이후의 사용자 정정을 우선했다. 강화학습 파라미터 학습으로 표현하지 않았다. 제어 인터페이스와 자세 확인은 로컬 AI 주행 코드 문서로 함께 확인하였다.

노래방의 성능 개선은 공개 저장소 `docs/PERFORMANCE_BENCHMARK.md`의 기존 최종 반복 평가를 사용했다. 9개 명령을 각 3회 측정한 조건에서 구조화 처리의 명령 정확도는 두 모델 모두 27/27이며 평균 응답시간은 8B 13.13초, 1.7B 4.83초다. 1.7B의 Raw 방식 22/27과 4.55초를 구조화 처리 27/27과 4.83초와 비교했다. 신규 측정이나 전체 음성 입력부터의 체감 응답시간으로 표기하지 않았고 LangChain 단독 효과로 일반화하지 않았다.

## 공개 범위

자격증과 군 복무의 고유 식별번호, API 키, 서버 설정, 개인 전화번호, 원본 발표 자료 전체를 포함하지 않는다. 원본 발표 자료는 변경하지 않았다.
